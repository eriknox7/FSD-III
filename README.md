# Student Management System

A React app to add, view, update, and delete student records. Built for Practical No. 03 (Frontend Technologies).

## Features

- Add / edit / delete student records
- Search by name or roll number
- Form validation (required fields, email format, duplicate roll number check)
- Stats overview (total students, courses, average grade)

## Run locally

```bash
npm install
npm run dev
```

Open the printed URL (usually `http://localhost:5173`).

## Build

```bash
npm run build
```

## Tech

React + Vite
